This git repo is used for the Learning Optimization module at BHT, FB VI.
This module relies on a practical study of machine learning, and optimize it to run on a constrained environment.

The modalities of this environment can be found on the website:

https://app.dynamic-pricing-competition.com/

Each week, after each class, a duopoly.py file needs to be uploaded on the DPC website to make it compete and get performance results.


The module is evaluated on the best 3 presentations out of 4.
The dates and contents of the presentations are the following:
- 3/11/2026
  Linear Regression - capacity utilization (target) curves vs. booking (sales) curves
  
- 8/12/2026
  Dynamic pricing - optimized pricing

- 19/01/2027
  Machine learning methods like random forest, XGB, ...
  
- 02/02/2027
  Best performance
